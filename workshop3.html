05Into n8n

Two kinds of automation. Both can be built with AI.

Standard
Fixed steps

A pre-defined path. Trigger → step → step → done, the same route every run. Predictable — and blind. It can't handle anything you didn't script.

Agentic
Embedded judgment

The same flow, with an agent inside that decides — reads the context, picks the path, handles the messy middle a fixed flow would choke on.

06When to use what

Same job, two tools.

Schedule
n8n

Reach for a Schedule when

The task is mostly judgment — summarise, triage, decide
A daily timer is trigger enough
Every source is already a connector
"Right most mornings" is good enough
Anyone who can write a prompt can build it

Reach for n8n when

Mostly mechanical, with judgment at one step
It must react to events, not just a clock
It has to reach systems Cowork can't
It must be production-grade — retries, logs, error paths
Volume is high — don't reason over every row
