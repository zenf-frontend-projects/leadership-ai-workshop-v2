05

A day living on the loop (instead of in the loop)

I start with /slack-summary — overnight messages, distilled to what matters. One needs a reply, so I draft it in seconds with /my-tone-of-voice.

It raises something worth digging into, so I run /product-research. It's 80% there — but I realise the skill doesn't prompt for a GTM strategy. I improve the skill to include it, so the next run is sharper, and stays that way permanently.

I write it up with /write-specs, which points at Confluence documents that hold the rules on how specs should be written — so the skill evolves with these documents over time. It looks great, and I'm not precious about it: the engineer reviewing it will run their own /review-specs, then /convert-into-tech-specs to finalise.

Before I log off, I open two Jira tickets with /create-roadmap-item and /create-launchpad-ticket. Done.
